# CREATE MY OWN LIFE | Portfolio Web

나만의 가치를 만드는 개발자, **장용민**의 포트폴리오 웹사이트입니다.  
Next.js 15 App Router와 Turbopack을 활용하여 빠르고 쾌적한 사용자 경험을 제공하도록 설계되었습니다.

## Tech Stack

### Frontend
- **Next.js 15 (App Router)**: 서버 및 클라이언트 컴포넌트 최적화 설계
- **TypeScript**: 안정적인 코드 베이스 구축
- **Framer Motion / CSS Scroll Snap**: 세련된 섹션 단위 스냅 스크롤링 구현

### Backend & DevOps
- **Firebase**: 호스팅 배경 이미지 및 프로젝트 PDF 데이터 관리
- **Vercel**: 지속적 배포(CD) 및 도메인 관리
- **Docker**: 개발 환경 표준화
- **Turbopack**: Rust 기반 고속 빌드 엔진 활용
